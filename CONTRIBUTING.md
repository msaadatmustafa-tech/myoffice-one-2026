# Contributing to MyOffice One

Use Node.js 24 or later. Clone the repository, run `npm ci`, then `npm test`. Launch the desktop application with `npm start`. Build the Windows installer with `npm run installer-win` on Windows x64.

Before opening a pull request, run the checks and describe the user-visible change. For import/export fixes, include a small generated sample and a regression check. Preserve the MIT license and third-party notices.

For bug reports, include Windows version, application version, exact steps, expected behavior and actual behavior. Remove private information from screenshots and sample documents. This project does not promise full Microsoft Office compatibility.
