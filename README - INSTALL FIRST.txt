MYOFFICE ONE 2026 - WINDOWS INSTALLATION
======================================
See README.md for complete features, compatibility, installation and troubleshooting.

FREE FOR EVERYONE: custom code is MIT licensed. Keep LICENSE.txt with redistributed copies.

INSTALL FROM SOURCE
1. Install Node.js 24 LTS with npm from https://nodejs.org/.
2. Extract the source ZIP into a writable folder.
3. Connect to the internet for build dependencies.
4. Double-click BUILD INSTALLER - Windows 11.cmd.
5. After a successful build, open dist-installer and run
   MyOffice-One-Setup-0.4.1-x64.exe.
6. Follow setup and approve the expected administrator prompt.

WITHOUT INSTALLING
Double-click Run MyOffice - No Install.cmd, or open index.html in Edge/Chrome.
This browser mode does not register Windows file associations.

UNINSTALL
Windows Settings > Apps > Installed apps > MyOffice One > Uninstall.

BACKUP AND COMPATIBILITY
Export your work to disk and retain originals. Complex Office features and
formatting may not survive import/export. Browser recovery storage is not a
permanent backup. This application is independent of Microsoft.
